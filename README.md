The XGBoost implementation in Python were part of my Master's thesis in Digital Health, which explored the use of sensor data visualisations to assist healthcare professionals in caring for people with dementia, identifying falls and monitoring activities of daily living, through a remote monitoring tool. The implementation was based on a dataset collected from volunteer participants at the University of Malta, performing activities of daily living and fall activities under controlled conditions. The machine learning aspect of the model aimed to further improve the collected dataset, detecting false positives to create a stronger model, thus improving the chances of finding a real fall of an individual living with dementia.
